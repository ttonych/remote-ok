# Remote OK 1.1.0

## Русский

Две поставки для Windows x64: отдельная программа **G60S OK** и дополнение **G60S OK for Kodi**. Первый поддерживаемый пульт — G60S Pro; обрабатывается только кнопка OK.

- Русский и английский интерфейс, сохранение выбранного устройства и настроек.
- Общий режим Windows и режим только MPC-BE / MPC-HC: Enter, воспроизведение/пауза или полный экран.
- Дополнение запускается и завершается вместе с Kodi. При одновременной работе с отдельной программой приоритет в Kodi имеет дополнение.
- Оба ZIP и вложенный EXE собраны в GitHub Actions из тега `v1.1.0`; контрольные суммы находятся в `SHA256SUMS.txt`.

**Физический пульт с версией 1.1.0 не проверен — пульта не было в наличии.** Не проверены реальные USB/Bluetooth-нажатия, переподключение и установка через ZIP-диалог Kodi. Пользователь разрешил публикацию с этими ограничениями.

Автоматически проверены декодирование HID, подавление повторов, выбор активного окна, приоритет Kodi, сохранение настроек и завершение обработчика. Программная интеграция проверена локально на Windows 10 x64, Kodi **21.3 / 22 RC1**, MPC-HC **2.8.3** и MPC-BE **1.9.2**. Интерфейс вручную осмотрен по свежим снимкам русского и английского окон. Kodi 22 final и Windows 11 не проверены. Работа старого прототипа с пультом ранее подтверждалась пользователем, но это не проверка релиза 1.1.0.

Для Windows распакуйте `G60S-OK-Windows-x64-1.1.0.zip` и запустите EXE. В Kodi установите `script.g60s.ok-1.1.0.zip` через «Установить из ZIP-файла». Завершите старые обработчики 1.0 и AutoHotkey-скрипты той же кнопки. Выключите аэромышь, выберите «Найти по OK», нажмите и отпустите OK, затем «Включить».

## English

Two Windows x64 packages: the **G60S OK** desktop app and **G60S OK for Kodi** add-on. G60S Pro is the first supported remote; only the OK button is handled.

- English/Russian UI with saved device and mapping settings.
- Global Windows or MPC-BE / MPC-HC-only scope; Enter, play/pause or fullscreen for MPC.
- Kodi starts/stops its helper automatically and takes priority over the desktop app inside Kodi.
- Both ZIPs and the bundled EXE are built in GitHub Actions from tag `v1.1.0`; see `SHA256SUMS.txt` for checksums.

**Version 1.1.0 has not been tested with a physical remote because none was available.** Real USB/Bluetooth presses, physical reconnection and Kodi's ZIP-install dialog remain untested. Publication with these limitations was explicitly approved.

Automated checks cover HID decoding, repeated-down suppression, foreground routing, Kodi priority, persistence and helper shutdown. Local software integration was tested on Windows 10 x64 with Kodi **21.3 / 22 RC1**, MPC-HC **2.8.3** and MPC-BE **1.9.2**. English and Russian windows were visually inspected using fresh screenshots. Kodi 22 final and Windows 11 were not tested. Earlier user confirmation of the old prototype is not hardware verification of this release.

Extract the desktop ZIP and run the EXE, or install the add-on ZIP using Kodi's “Install from zip file”. Exit old 1.0 helpers and AutoHotkey scripts for the same button. Turn off air mouse mode, use “Find by OK”, press and release OK, then click “Enable”.
