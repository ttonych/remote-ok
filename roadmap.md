# G60S OK — roadmap

Две версии для Windows x64: **GUI-программа** и **дополнение Kodi 21/22**. Пока работаем только с кнопкой OK, без удержания и двойного нажатия.

**Состояние 1.1.0:** [релиз опубликован](https://github.com/ttonych/remote-ok/releases/tag/v1.1.0), программные проверки выполнены. Пользователь разрешил публикацию без физического пульта; проверка пульта и установки через ZIP-интерфейс Kodi остаётся отложенной и явно отмечена в релизе. Подробности — в [отчёте](docs/testing.md).

## Опубликовать

- [x] Перенести готовый проект в публичный репозиторий и настроить GitHub Actions: [ttonych/remote-ok](https://github.com/ttonych/remote-ok).
- [x] Из тега версии собрать и проверить оба ZIP в Actions, опубликовать релиз с SHA-256.

**Правило:** разработка и отладка — локально. Публичные релизные бинарники и архивы — только из GitHub Actions, собранные из исходников тега. Подробные правила — в [AGENTS.md](AGENTS.md).
